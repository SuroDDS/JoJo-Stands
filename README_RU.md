# JoJo Stand System — прототип 0.1

**Поддерживаемая версия проекта:** RimWorld **1.7**, DLC **Biotech** и мод **Harmony** с Harmony 3 для RimWorld 1.7.

**Важно:** это **архив с исходниками**, не готовый для запуска мод. `JoJoStand.dll` в архиве отсутствует: её необходимо собрать на компьютере с установленной RimWorld 1.7. Исходники и XML проверены на уровне структуры; компиляция и проверка непосредственно в игре ещё не выполнены. Не подключайте мод к основному сохранению до тестов.

## Что написано

1. **Stand Core.** Состояние стенда хранится непосредственно в пешке через собственный `Hediff_StandBond`: скрытый потенциал, стенд, призыв, откат способности. Данные сериализуются в сохранение.
2. **Stand Arrow.** Есть предмет «Stand Arrow». Если Стрела лежит на одной или соседней клетке с колонистом либо в его инвентаре, появляется команда использования.
3. **Пробуждение.** Стрела расходуется. Шанс успеха у пешки без потенциала по умолчанию 55%, со скрытым потенциалом — 90%. При провале можно получить тяжёлую рану, иногда умереть. Все эти числа — временные настройки прототипа.
4. **Star Platinum.** Единственный стенд на этом этапе. Добавлены призыв, отзыв и дистанционная на 2,9 клетки ударная способность с перезарядкой.
5. **Наследование.** Периодическое обнаружение новорождённых из Biotech и расчёт потенциала по родителям (50% при одном носителе, 85% при двух, 2% без носителей). Это начальная механика, а не полноценный обработчик момента родов.
6. **NPC и животные.** По настройкам могут получить стенд при попадании на карту. Чужие пешки со Star Platinum автоматически наносят удар по противнику рядом. ИИ диких животных пока не реализован.
7. **Настройки, русский и английский интерфейс.**

## Сборка на Windows

1. Нужны **.NET SDK 10**, установленная **RimWorld 1.7** и **Harmony** для 1.7.
2. Распакуйте архив в папку с исходниками (или сразу в `<RimWorld>/Mods/JoJoStandPrototype/`).
3. Откройте PowerShell в папке `JoJoStandPrototype` и выполните:

   ```powershell
   .\build.ps1 -RimWorldDir 'C:\Program Files (x86)\Steam\steamapps\common\RimWorld'
   ```

   Путь — пример. Подставьте фактическую папку RimWorld, где находятся `Assembly-CSharp.dll`, `UnityStubs.dll` и `Waylith.dll`.

4. После успешной компиляции появится `1.7/Assemblies/JoJoStand.dll`.
5. Положите всю папку `JoJoStandPrototype` в `<RimWorld>/Mods/` и включите **Harmony → Biotech → JoJo Stand System — Prototype**. Перезапустите игру.

**Harmony.dll внутрь нашего мода не копируем.** Мод использует установленную Harmony.

## Проверка в игре

1. Создайте **новое тестовое сохранение** и включите режим разработчика.
2. Через **Spawn thing** создайте `Stand Arrow` (`JJ_StandArrow`) рядом с любым колонистом.
3. Выберите колониста. Появится команда **«Использовать Стрелу»**. Если её нет, проверьте расположение Стрелы и загрузку DLL.
4. После удачного пробуждения появится «Призвать стенд». Нажмите, затем «Удар стенда», выберите цель поблизости.
5. Проверьте, что удар проходит не далее 2,9 клетки, имеет перезарядку, а после отзыва способность недоступна.
6. Сохраните и загрузите игру: стенд и его состояние должны сохраниться.

Подробная программа тестирования — `Tests/TEST_PLAN.md`.

## Ограничения версии 0.1

- Пока **нет 3D/2D фигуры Star Platinum**; призыв переключает логическое состояние. Невидимость заложена в интерфейс кода, но **система восприятия и отображения стендов не завершена**.
- Стенд не является дополнительной пешкой, поэтому нет отдельного получения урона стендом с передачей владельцу.
- **Time Stop, Harvest, Cheap Trick, Hamon, Spin, Requiem** отсутствуют.
- Стрела пока не имеет полноценной процедуры/задания, способной выполняться NPC.
- Персонажи вне загруженных карт получают шанс стать стенд-юзером при первом появлении на карте.
- Вероятности выбора «достойного» пока не учитывают черты и биографию; они настраиваемые и требуют балансировки.
- Некоторые изменения настроек могут повлиять на ранее встреченных пешек, которым ещё не был назначен потенциал.

На следующем этапе нужно добиться чистого запуска в 1.7, проверить сохранение, затем разработать **визуальный слой и обнаружение стендов**. Только после этого разумно масштабировать каталог.
