# v0.2.0 — Star Platinum manifestation smoke test

Experimental visualization only, built on top of `dev/v0.1.2-stability`.

## Build / deploy

1. Close RimWorld.
2. Checkout `dev/v0.2.0-manifestation`; build with `build.ps1` against your installed RimWorld 1.7 libraries.
3. Ensure game loads **new DLL, new Languages XML and new PNG** from the same mod folder. If the repo is in `C:/Dev`, copying only DLL is **not enough**:
   - `1.7/Assemblies/JoJoStand.dll`
   - `Languages/Russian/Keyed/JoJoStand.xml` (and English as applicable)
   - `Textures/Things/StandManifestation/StarPlatinum.png`
4. Enable **Show Stand manifestations** in mod settings.

## Test scenarios

- [ ] No new red errors on start and on map load.
- [ ] After successful Stand Arrow awakening, select a colonist and press Manifest Stand.
- [ ] Purple placeholder silhouette appears slightly behind/next to owner.
- [ ] Move the owner; the silhouette follows every frame.
- [ ] Recall Stand; the silhouette disappears.
- [ ] Resume Manifest; it reappears.
- [ ] Execute a successful short-range punch: the sprite briefly shifts forward.
- [ ] Punch damage/cooldown and `[COMBAT][HIT]` logs remain unchanged.
- [ ] A pirate with a Stand that attacks in melee becomes manifested and displays the same silhouette.
- [ ] Disable **Show Stand manifestations**; silhouettes disappear without changing combat.
- [ ] Save game while manifested, quit and reload: visuals follow saved `Manifested` flag.
- [ ] Kill / down owner, remove owner from map, travel by caravan: no lingering silhouette or exceptions.
- [ ] Test pause, x1 and x3 speed; ensure no unbounded log spam.

## Known constraints
- This is a **temporary original debug silhouette**, not a production JoJo asset.
- Rendering is omniscient and purely visual. **Per-pawn visibility / AI perception are NOT implemented** in this build.
- No independent Thing or Pawn exists for the Stand. No Stand collision, independent pathing, damage transfer or physical targetability.
- Position and attack movement are illustrative. Owner's facing and draw layer may need tuning on the exact 1.7 beta version.
- Stand animations are based on game ticks and pause while the game is paused.
- Initial owner list is refreshed every 60 game ticks; after natural awakening, the sprite may appear with up to one second delay.

## Troubleshooting

- **No option in mod settings**: old DLL and/or old Language XML is loaded.
- **Option exists but no sprite**: check `Textures/Things/StandManifestation/StarPlatinum.png` exists in the installed mod folder and verify the pawn has an awakened, manifested `JJ_StarPlatinum`.
- **No visual for NPC**: NPC must have already used its Stand. It only auto-manifests when it has a valid hostile target in melee range.
- **Rendering exceptions**: copy the entire red exception + stack trace; do not merge the PR until fixed.

## Definition of done

Compile on local RimWorld 1.7 DLLs and pass the scenarios above in-game before merge.
