# v0.2.2 — Star Platinum gameplay sprite atlas

## Implemented
- The old opaque single-direction placeholder was removed from `Textures/Things/StandManifestation/StarPlatinum.png`.
- New **transparent** atlas: `Textures/Stands/JJ_StarPlatinum/StarPlatinumAtlas.png`.
- 4 columns: South / East / North / West; 2 rows: Idle / Attack. 64 × 64 pixels per atlas cell (256 × 128 total).
- `StandManifestationMapComponent` now selects the correct UV mesh for each direction and plays an Attack frame on a successful `StandSystem.Punch` event.
- Follow-owner, idle bob, lunge and existing show/hide setting continue working.
- No changes to damage rules or autonomous NPC logic.

## Asset provenance / limitations
Generated specifically for this mod using an original AI concept sheet based on the project's `VISUAL_BIBLE.md` guidance. Characters were extracted and alpha-matted from a dark concept-sheet background, with a limited-color sprite atlas for efficient in-game rendering.
This is an **experimental art integration**, not yet a hand-polished production-ready sprite. It may show hard edges around some limbs or edge halos from the concept extraction.
Only *Idle* and *Attack* have separate artwork. Manifest/Recall still simply appear/disappear using the existing `Manifested` flag; dedicated transitions are future work.

## How to install

1. Close RimWorld.
2. Checkout `dev/v0.2.2-star-platinum-sprites`.
3. Build against your RimWorld 1.7 assemblies, e.g. using `build.ps1`.
4. Ensure that the **installed** mod folder gets BOTH:
   - `1.7/Assemblies/JoJoStand.dll`
   - `Textures/Stands/JJ_StarPlatinum/StarPlatinumAtlas.png`
5. If settings are missing, also update the `Languages` folder.
6. Relaunch RimWorld (textures may be cached until restart).

## Architecture notes
Current UV atlas implementation is deliberately local to Star Platinum. General `StandVisualDef` and renderer-provider registry from `STAND_VISUAL_SCHEMA.md` are **not implemented yet**.
The atlas uses eight cached meshes and one cached material; it does **not** allocate textures or meshes for each pawn or draw call. 
Transparency is baked into the atlas. Direction offsets and owner-size scaling still need validation in-game.

## Stop conditions
If the sprite is sideways, invisible, has a solid rectangle, or Unity reports an error, capture the red error with stack trace and attach a screenshot. Do not merge until the gameplay rendering is confirmed.
