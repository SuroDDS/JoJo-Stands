# v0.2.3 — Stand Scale Pass

## Scope
- Star Platinum render `DrawScale`: **1.10 -> 1.55** (about +41% nominal width/height, not a guarantee of visible body coverage).
- Adjusted rear-side positional offsets separately for South/East/North/West to reduce owner overlap.
- No changes to Stand game mechanics, cooldown, damage, save format or sprite PNG.
- Documents require a size class and dominance level for all future Stand visual assets.

## Install / test
1. Close RimWorld and switch to `dev/v0.2.3-scale-pass`.
2. Build with the project's `build.ps1` against your installed RimWorld 1.7 files.
3. Replace the DLL in the **actual installed mod** folder. The existing atlas from v0.2.2 remains required.
4. Load a save with an awakened Star Platinum and summon it next to a regular colonist.

## Acceptance checks
- [ ] Star Platinum looks like a Heavy humanoid, not a tiny follower.
- [ ] Owner remains identifiable with Stand at idle, attacking, facing South/East/North/West.
- [ ] Sprite stays aligned behind and beside the owner during walking.
- [ ] Attacks still emit `[JoJoStands][COMBAT][HIT]`; no changes to damage/cooldown.
- [ ] No dark rectangular background or clipping into pawn UI.
- [ ] Same result after save/reload and in rain/night/grass.
- [ ] Test at normal 1080p zoom and maximum practical zoom; compare to an adult pawn.
- [ ] Report screenshots with direction, zoom and whether owner is behind/in front of the Stand.

## Caution
Scale applies to the **whole atlas quad**, including transparent padding. If visible figure still looks too small, re-crop and repack the sprite atlas before blindly raising DrawScale. Check render order when rotating.
This is a small calibration patch, not yet a generalized runtime `StandVisualDef` implementation.
